# IPO Fast Check

### Fast. Simple. IPO allotment checking.

A fast, mobile-friendly website for checking recent Indian IPO allotment results and viewing current Grey Market Premium (GMP) information.

[![Live Website](https://img.shields.io/badge/Live_Website-ipoinfo.online-111111?style=for-the-badge)](https://ipoinfo.online)

**Mainboard IPOs | SME IPOs | Allotment Status | GMP**

</div>

---

## Features

- Check one PAN against a recently completed IPO.
- Automatically begin checking when a valid PAN is entered.
- Display clear **Allotted**, **Not Allotted**, **Not Applied**, **Pending**, and **CAPTCHA Required** states.
- Browse **Open**, **Upcoming**, and recently **Closed** IPOs.
- View **GMP, price band, lot size, important dates, and estimated listing price**.
- Use a responsive interface designed for mobile and desktop.

---

## How It Works

1. Select a recently completed IPO.
2. Enter a valid PAN number.
3. View the allotment result or complete the official registrar CAPTCHA when required.

---

## Privacy & Data Safety

> **Your PAN and personal information are never stored on our server, in a database, or in server logs.**

- PAN information is used only to perform the allotment check requested by the user.
- Allotment results and personal details are not retained after the request is completed.
- PAN values are never included in website URLs.
- The optional **Remember PAN on this device** setting stores the PAN only in that user's browser. It is never sent to our database and can be disabled at any time.
